# Triage Labels

Skill berbicara dalam lima peran triage kanonik. File ini memetakan peran tersebut
ke string label yang dipakai di issue tracker repo ini.

| Label di mattpocock/skills | Label di tracker kami | Arti                                     |
| -------------------------- | --------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`        | Maintainer perlu mengevaluasi issue ini  |
| `needs-info`               | `needs-info`          | Menunggu pelapor untuk informasi tambahan |
| `ready-for-agent`          | `ready-for-agent`     | Sudah terspesifikasi penuh, siap untuk agent AFK |
| `ready-for-human`          | `ready-for-human`     | Butuh implementasi manusia               |
| `wontfix`                  | `wontfix`             | Tidak akan dikerjakan                    |

Saat sebuah skill menyebut sebuah peran (mis. "apply the AFK-ready triage label"),
pakai string label yang sesuai dari tabel ini.

Edit kolom kanan untuk menyesuaikan dengan kosakata yang benar-benar dipakai.
